JOB PORTAL - BASIC REACT PROJECT

Features:
- Black-and-white responsive UI
- Homepage with navigation
- Eight sample job cards
- Job title, company, location, salary, job type and experience
- Apply Now button with a simple alert
- About and Contact sections
- No sign-in or sign-up page

HOW TO RUN ON WINDOWS:

1. Extract the JOB PORTAL file.
2. Open the extracted job-portal-basic folder in VS Code.
3. Open Terminal > New Terminal.
4. Make sure the terminal is in the folder containing package.json.
5. Run:

   npm.cmd install

6. When installation finishes, run:

   npm.cmd start

7. Open http://localhost:3000 in your browser.

Note:
The job listings are sample data for learning purposes. They are not verified live vacancies.
